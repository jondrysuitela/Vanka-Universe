# Musik Vanka Experience

Letakkan file lagu di folder ini. Pemutar mencari, berurutan:

| File | Dipakai untuk |
|---|---|
| `vanka-1.mp3` | edisi usia 1 (2026) — lagu khusus tahun itu |
| `vanka-2.mp3` … `vanka-17.mp3` | edisi tahun-tahun berikutnya |
| `vanka.mp3` | cadangan untuk edisi yang belum punya lagu sendiri |

Catatan:

- **Nama file harus persis** seperti di atas (huruf kecil, ekstensi `.mp3`).
- Kalau hanya ada `vanka.mp3`, semua edisi memakainya.
- Kalau **tidak ada file sama sekali**, situs tetap berjalan normal — musik
  tidak berbunyi dan tombol mute tidak muncul (bukan tombol mati).
- Musik mulai otomatis saat pengunjung membuka kotak hadiah, memudar masuk
  selama ~1,6 detik, dan terus berulang.
- Pilihan mute pengunjung disimpan di browser, jadi tidak dipaksa berbunyi lagi
  saat kembali.
